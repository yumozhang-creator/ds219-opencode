# StudyFlow

StudyFlow is a one-page study planner for college students. It helps track upcoming deadlines and keep quick study notes in a clean, responsive interface.

## Run locally with Python

1. Open a terminal in the project folder.
2. Start a local server:

   ```bash
   python3 -m http.server 8000
   ```

3. Open your browser and go to:

   ```
   http://localhost:8000
   ```

No dependencies or build steps are required.
