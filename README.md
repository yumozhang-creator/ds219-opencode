# StudyFlow

StudyFlow is a one-page study planner designed for
college students.

It helps students organize upcoming deadlines and
keep quick study notes in a clean, responsive interface.

## Features

- Add and delete deadlines
- Highlight overdue deadlines in red
- Add study notes
- Save information using browser localStorage
- Responsive design for mobile and desktop

## Prerequisites

Python 3 must be installed.

No additional packages or dependencies are required.

## Run Locally

1. Open Terminal.
2. Navigate to the project folder.
3. Run:

   python3 -m http.server 8000 --bind 127.0.0.1

4. Open your browser and visit:

   http://localhost:8000

## Stop the Server

Return to the terminal running the server.

Press Ctrl + C to stop it.
