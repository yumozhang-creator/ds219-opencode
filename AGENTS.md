# Project Constraints

- Build StudyFlow as a one-page website using only `index.html`, `style.css`, and `script.js`.
- Do not install packages or deploy anything.
- Keep all project files inside this repository.
- Keep the design clean, modern, and responsive for mobile and desktop.
- Preserve keyboard accessibility.
- Wait for approval before building or changing website functionality.
- Do not modify website functionality unless explicitly requested.
- Do not commit or push changes automatically.
